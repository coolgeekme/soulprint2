*SoulPrint Passport — how we go to market with ~zero budget*

*Where we actually stand*
- ~200 registered users, 0 paying
- All of them registered for the *original SoulPrint Engine* — the all-in-one chat app (multi-model, image/video gen), not Passport
- That distinction drives everything below

*The insight that changes the plan*
At 15% conversion, 200 users is ~30 paying customers. That's not revenue, it's a signal.

So the bottleneck is *not* getting more traffic. It's that 200 warm people signed up and didn't convert. If we can't fix that, cold traffic won't fix it either.

The 200 are our lab, not our market. Their job: prove the activation-to-paid path works, produce testimonials, and tell us the real objections.

*The catch we have to respect*
They opted into a *destination* — "all your AI in one place." Passport is the opposite behavior — stay in ChatGPT and Claude, we follow you.

If we blast all 200 with "you're in the beta," we set up a mismatch. Some wanted free image/video generation and will be annoyed by a memory extension pitch. That burns trust and hurts our email reputation.

So: *segment, don't blast.*

*Who the 200 actually are*

- *A. Depth users* — completed the 36-question assessment, or have real memories. These are our actual beta cohort. Warmest, highest converting.
- *B. Touched it* — logged in, poked around, never went deep. Deserve the honest "we changed direction" note.
- *C. Signed up, never used* — one honest email, then leave them alone.
- *D. Wanted the old thing* — heavy media-gen / model-switching users. Point them to The Foundry. Don't pitch Passport.

Segment A is the beta. Everyone else gets a different, honest message.

*The plan*

*Phase 0 — make the offer real (before promoting anything)*
Build the broadcast email path (we have sendEmail but no way to email all users today). Lock the offer: founding beta, first 100, pricing locked in.

*Phase 1 — ignite segment A*
One email, one CTA: take the Assessment. It solves the cold-start problem — a memory product with no memories does nothing, and that's the #1 killer in this category. The Assessment front-loads a real SoulPrint in one sitting, so the extension has something to work with on day one.

*Phase 2 — free loops that fit this product*
MCP directories + awesome-lists, AI tool directories, Chrome Web Store, Reddit, founder-led LinkedIn, podcast/newsletter guesting.

*Phase 3 — compounding*
Own the category "portable AI memory." Ship /mcp and /what-is-ai-identity pages. Answer the questions people actually search. Free distribution that gets cheaper over time.

*Phase 4 — referral loop*
Only after retention proves out. The Assessment result is inherently shareable.

*What we are NOT doing*
- Paid ads — at $12–14/mo, CAC eats LTV alive
- Influencers — no budget, and trust-transfer is weak for a privacy product
- Blasting every platform — pick LinkedIn, Reddit, directories
- Building more features — we have 65 Imprints, an assessment engine, extension, MCP. Distribution is the constraint, not product.

*The one metric*
Not signups. *Activated users* — completed assessment → installed extension → returned in week 2. Then paid conversion of that cohort. Everything above exists to move that number.

*The story we tell the 200*

Not a launch blast. A pivot story:

> "We built an all-in-one AI app. 200 of you showed up. We learned the thing you actually needed wasn't another place to chat — it was AI that remembers you wherever you already are. So we built that instead."

Credible, human, gives people a real choice instead of assuming.

*Why the Assessment leads everything*

A memory product is worthless on day one — it has nothing to remember. Most people churn before enough memories accumulate to feel it.

The Assessment is our answer: 36 questions, 6 pillars. It front-loads a real SoulPrint in one sitting, so the extension has something to do immediately.

*Why Imprints matter for revenue*

65 in the catalog — Business Coach, Career Advisor, Financial Advisor, Startup Mentor, Executive Coach. Nobody else pairs portable memory with persistent working modes. Imprints are also a natural paid reason: they change how the AI *thinks*, not just what it knows.

*What we need*

1. *From Reggie* — the user export (admin panel → users/export), so we can segment A/B/C/D properly
2. *Confirm* — what does one of those 200 see when they log in today? If the app still offers chat while the site sells a memory layer, we need to resolve that before telling 200 people the story changed
3. *Volunteers* — directory submissions and Reddit/LinkedIn drafts are ready to go, just need someone to execute

*Timing*
Everything is gated on the Chrome Web Store listing going live. The Assessment works today, so Phase 1 can run before CWS — with the install step following once it's approved.

*Free upside we shouldn't waste*
Those 200 are free research on why product #1 didn't convert. "200 signups, 0 paying" has a cause — crowded category, unclear job-to-be-done, wrong positioning. Cheaper to learn now than from 2,000 cold users later.

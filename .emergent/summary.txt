**Key Technical Concepts**
-   **Disk-based Chunked File Upload**: The core solution for large file imports. Files are split into 5MB chunks on the client, sent sequentially to the backend, written to temporary files on disk, reassembled, processed, and then deleted. This avoids server memory limits.
-   **Stream-based File Processing**: The reassembled file is processed using streams to remain memory-efficient.
-   **Client-side  Hook**: Used to prevent users from accidentally navigating away from the page and interrupting an in-progress upload.
